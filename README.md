# ⚡📱 React Social Media Post Component ⚡📱

🇺🇸 English / 🇧🇷 Português Brasileiro

---

## 🇺🇸 Overview
- 🖼️ Responsive social media post component in React
- 📝 Displays an image, text, and interactive buttons (❤️ Like, 💬 Comment, ✉️ Share, 🔖 Save)
- 📊 Dynamic like and comment counters
- 🎨 Instagram-style UI/UX with hover and click effects
- 🧩 Modular and easy to integrate in larger apps

### 🧩 Requirements
- 💻 Node.js (Vite officially supports 14.18+ / 16+)
- ⚛️ React 18+
- 🎨 CSS3

### 💡 Concepts used
- ⚛️ React functional components and hooks (useState)
- 🖱️ Event handling (onClick)
- 🔄 Conditional rendering for icons
- 📐 CSS Flexbox
- 🎛️ Interactive UI patterns

### 🚀 How to run
- git clone https://github.com/DevYuriVieira/react-social-post.git
- cd react-social-post
- npm install
 -npm start


### 🌱 Future improvements
- 📰 Multiple posts feed with infinite scroll
- 💬 Comment section with nested replies
- 🗄️ Backend for persistent likes/comments/saves
- 👤 User profiles with avatars
- ♿ Accessibility improvements
- 🌗 Light/dark theme toggle
- 🤖 Optional AI-powered content suggestions (ideas only)
